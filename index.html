Gerar a planilha no Mac

Passo a passo para rodar os scripts da pasta codigo num Mac. Na primeira vez leva uns 15 minutos. Das próximas vezes, basta fazer os passos 3 e 5.

Você vai precisar de:
  • um Mac com internet
  • o arquivo Universal2026 - Pacote Laerte.zip
  • a senha do Mac (para instalar o Python)
1 Instalar o Python 2 Descompactar a pasta 3 Abrir o Terminal na pasta 4 Instalar as bibliotecas 5 Rodar os scripts 6 Abrir a planilha Se der erro

Passo 1 só na primeira vez

Instalar o Python

O Mac não vem com o Python pronto para uso. Instale a versão oficial.

  1. Abra python.org/downloads e clique no botão amarelo Download Python 3.x.x. O número pode ser outro; qualquer versão 3.12 ou mais nova serve.
  2. Abra o arquivo baixado (python-3.x.x-macos11.pkg, na pasta Transferências).
  3. Clique em Continuar em cada tela. Na licença, clique em Concordo. Depois, Instalar e digite a senha do Mac.
  4. Na mensagem de instalação concluída, clique em Fechar. Pode fechar também a janela do Finder que abre sozinha.

Se o Mac oferecer instalar as “ferramentas de linha de comando”, clique em Cancelar. Não são necessárias.

Passo 2

Descompactar a pasta

  1. No Finder, vá até onde salvou o zip (normalmente Transferências) e dê dois cliques em Universal2026 - Pacote Laerte.zip. Aparece uma pasta com o mesmo nome.
  2. Abra a pasta e confira: a pasta codigo fica junto com as planilhas, no mesmo nível.

Não renomeie nem mova nada lá dentro. Os scripts procuram as planilhas pelo nome exato. Se o Mac criar cópias como arquivo (1).xlsx por download repetido, apague a pasta e descompacte de novo.

Passo 3

Abrir o Terminal na pasta

  1. Aperte ⌘ Command + espaço, digite terminal e aperte Enter.
  2. No Terminal, digite cd e um espaço. Não aperte Enter ainda.
  3. Arraste a pasta Universal2026 - Pacote Laerte do Finder para dentro da janela do Terminal. O caminho da pasta aparece escrito.
  4. Aperte Enter. O nome da pasta passa a aparecer antes do %.
  5. Para conferir, digite ls e aperte Enter. Tem que aparecer a lista de arquivos, com codigo no fim.
ls

Se o Mac perguntar se o Terminal pode acessar a pasta Transferências, clique em Permitir. No Terminal essa pasta se chama Downloads; é a mesma.

Outra forma: botão direito na pasta

Precisa ativar uma vez: menu › Ajustes do Sistema › Teclado › botão Atalhos de Teclado… › Serviços › Arquivos e Pastas › marque Novo Terminal na Pasta.

Depois disso, clique com o botão direito na pasta (ou Control + clique) › Serviços › Novo Terminal na Pasta. O Terminal já abre dentro dela e você pode pular para o item 5 acima.

Passo 4 só na primeira vez

Instalar as bibliotecas

Com o Terminal aberto na pasta, confira se o Python está instalado:

python3 --version

Deve responder Python 3. seguido da versão. Depois instale as duas bibliotecas que os scripts usam:

python3 -m pip install pandas openpyxl

Espere o % voltar. Deu certo se a última linha começar com Successfully installed. Se aparecer um aviso de que há uma versão nova do pip, ignore.

No Mac o comando é sempre python3, nunca python.

Os números de versão no seu Mac podem ser outros.

Passo 5

Rodar os scripts

5.1 Conferir (não altera nada)

python3 codigo/VERIFICA_PLANILHA_LAERTE.py

Leva alguns segundos. Deu certo se terminar com OK: (1) 100% IDENTICO. Se a planilha já foi preenchida à mão, ele lista diferenças; nesse caso é esperado.

5.2 Gerar a planilha

Este script substitui a planilha TRABALHO LAERTE - …xlsx. Se você já preencheu alguma coluna nela, faça uma cópia antes com o comando abaixo. Feche a planilha no Excel antes de rodar.

cp "TRABALHO LAERTE - Planilha de Pontuação (19 propostas) - Edital Universal 2026.xlsx" "COPIA - planilha preenchida.xlsx"
python3 codigo/GERA_PLANILHA_LAERTE.py

Deu certo se aparecer OK - arquivo gerado: seguido do caminho da planilha.

As linhas em cinza foram resumidas aqui. No seu Terminal aparecem completas.

Passo 6

Abrir a planilha

Dê dois cliques na planilha no Finder, ou abra pelo Terminal:

open "TRABALHO LAERTE - Planilha de Pontuação (19 propostas) - Edital Universal 2026.xlsx"

Use o Excel. Os comentários das colunas T a Y aparecem ao passar o mouse sobre as células. O Numbers abre o arquivo, mas não salve por cima com ele.

Das próximas vezes: passo 3 (abrir o Terminal na pasta) e passo 5 (rodar).

Se der erro

Mensagem no TerminalO que fazer
command not found: pythonUse python3.
command not found: python3, ou janela pedindo “ferramentas de linha de comando”O Python não foi instalado (passo 1), ou o Terminal estava aberto durante a instalação. Feche o Terminal com ⌘ Q, abra de novo e refaça o passo 3.
ModuleNotFoundError: No module named 'pandas' (ou 'openpyxl')Faça o passo 4.
error: externally-managed-environment O Python instalado é o do Homebrew. Rode estes três comandos, um de cada vez:
python3 -m venv ~/venv-planilha
source ~/venv-planilha/bin/activate
pip install pandas openpyxl
Toda vez que abrir o Terminal, rode o comando do meio antes do passo 5.
cd: no such file or directoryDigite cd, um espaço, e arraste a pasta de novo. Não digite o caminho à mão.
can't open file … VERIFICA_PLANILHA_LAERTE.py ou FileNotFoundError … .xlsxO Terminal não está na pasta certa, ou algum arquivo foi renomeado ou movido. Rode ls e compare com a lista do passo 3.
PermissionError ou Operation not permittedFeche a planilha no Excel. Se continuar, vá em › Ajustes do Sistema › Privacidade e Segurança › Arquivos e Pastas › Terminal e ative Pasta Transferências.
