Gerar a planilha no Mac

Passo a passo para rodar os scripts da pasta codigo num Mac. Na primeira vez leva de 5 a 15 minutos. Das próximas vezes, basta fazer os passos 2 e 5.

Você vai precisar de:
  • um Mac com internet
  • o arquivo Universal2026 - Pacote Laerte.zip
1 Descompactar a pasta 2 Abrir o Terminal na pasta 3 Ver se já tem Python Instalar o Python (se faltar) 4 Instalar as bibliotecas 5 Gerar e conferir 6 Abrir a planilha Se der erro

Passo 1

Descompactar a pasta

  1. No Finder, vá até onde salvou o zip (normalmente Transferências) e dê dois cliques em Universal2026 - Pacote Laerte.zip. Aparece uma pasta com o mesmo nome.
  2. Abra a pasta e confira: a pasta codigo fica junto com as planilhas, no mesmo nível.

Não renomeie nem mova nada lá dentro. Os scripts procuram as planilhas pelo nome exato. Se o Mac criar cópias como arquivo (1).xlsx por download repetido, apague a pasta e descompacte de novo.

Passo 2

Abrir o Terminal na pasta

O Terminal é o programa onde se digitam os comandos. Ele precisa estar “dentro” da pasta do pacote para os scripts acharem as planilhas.

2.1 Abrir o Terminal

  1. Aperte as teclas ⌘ command e espaço juntas. Abre uma barra de busca no meio da tela (o Spotlight).
  2. Digite terminal.
  3. Aperte Enter. Abre uma janela com um texto terminado em %.
Não abriu? Pelo Finder

Abra o Finder e vá em Aplicativos › pasta Utilitários › dois cliques em Terminal.

2.2 Entrar na pasta arrastando

Esta é a parte que mais confunde. Veja a animação e depois faça igual.

  1. Deixe o Finder (com a pasta Universal2026 - Pacote Laerte à vista) e o Terminal lado a lado. Se o Terminal cobrir o Finder, arraste o Terminal pela barra de cima para o lado.
  2. Clique na janela do Terminal e digite cd seguido de um espaço. Não aperte Enter.
  3. No Finder, clique na pasta e segure o botão. Sem soltar, arraste até dentro da janela do Terminal.
  4. Solte. O caminho da pasta aparece escrito depois do cd.
  5. Agora sim, aperte Enter. O nome da pasta passa a aparecer antes do %.
  • Arraste a pasta inteira, não um arquivo de dentro dela.
  • Se soltou antes de digitar o cd, ou se algo saiu errado, apague a linha com control + U e comece de novo.
  • Se o Mac perguntar se o Terminal pode acessar a pasta Transferências, clique em Permitir.
  1. Digite cd e espaço
  2. Clique na pasta e segure
  3. Arraste até o Terminal e solte
  4. Aperte Enter

2.3 Conferir

Confirme que o Terminal está na pasta certa.

  1. Clique em Copiar neste comando:
    ls
  2. Clique dentro da janela do Terminal e cole com ⌘ command + V. O comando aparece escrito depois do %.
  3. Aperte Enter.
  4. Confira: aparece a lista de arquivos da pasta, com codigo perto do fim, como na imagem. Se aparecer outra coisa, repita o 2.2.

No Terminal a pasta Transferências aparece como Downloads. É a mesma pasta.

Outra forma de entrar na pasta: botão direito

Precisa ativar uma vez: menu da maçã (canto superior esquerdo) › Ajustes do Sistema › Teclado › botão Atalhos de Teclado… › Serviços › Arquivos e Pastas › marque Novo Terminal na Pasta.

Depois disso, clique com o botão direito na pasta (ou control + clique) › Serviços › Novo Terminal na Pasta. O Terminal já abre dentro dela, sem precisar arrastar.

Passo 3

Ver se já tem Python

  1. Clique em Copiar neste comando:
    python3 --version
  2. Clique dentro da janela do Terminal e cole com ⌘ command + V. O comando aparece escrito depois do %.
  3. Aperte Enter.
  4. Veja qual das três respostas abaixo apareceu e siga o que está escrito nela.

Só se no passo 3 deu B ou C

Instalar o Python

Se no passo 3 apareceu a versão do Python, pule esta parte.

  1. Abra python.org/downloads e clique no botão amarelo Download Python 3.x.x.
  2. Abra o arquivo baixado (python-3.x.x-macos11.pkg, na pasta Transferências).
  3. Clique em Continuar em cada tela. Na licença, clique em Concordo. Depois, Instalar, e digite a senha do Mac.
  4. No fim, clique em Fechar. Pode fechar também a janela do Finder que abre sozinha.
  5. Feche o Terminal com ⌘ command + Q, abra de novo, refaça o passo 2 e confira com python3 --version.

O Terminal só enxerga o Python novo depois de ser fechado e aberto de novo.

Passo 4 só na primeira vez

Instalar as bibliotecas

Os scripts usam duas bibliotecas do Python (pandas e openpyxl). Instale-as assim:

  1. Clique em Copiar neste comando:
    python3 -m pip install pandas openpyxl
  2. Clique dentro da janela do Terminal e cole com ⌘ command + V. O comando aparece escrito depois do %.
  3. Aperte Enter.
  4. Espere. Vão aparecer várias linhas e pode levar um ou dois minutos. Terminou quando o % aparecer de novo na última linha.
  5. Confira: a linha logo acima do % começa com Successfully installed. Avisos sobre versão nova do pip podem ser ignorados.

No Mac o comando é sempre python3, nunca python.

Os números de versão no seu Mac podem ser outros.

Passo 5

Gerar e conferir a planilha

5.1 Gerar a planilha

Este comando lê as três planilhas originais da pasta (v8, Editável Demanda e Vertical da TI) e monta a planilha TRABALHO LAERTE - …xlsx, substituindo a que está na pasta.

Só se você já preencheu notas nessa planilha: antes de gerar, salve uma cópia. Copie o comando abaixo, cole no Terminal e aperte Enter. Se ainda não preencheu nada, pule.

cp "TRABALHO LAERTE - Planilha de Pontuação (19 propostas) - Edital Universal 2026.xlsx" "COPIA - planilha preenchida.xlsx"
  1. Se a planilha estiver aberta no Excel, feche.
  2. Clique em Copiar neste comando:
    python3 codigo/GERA_PLANILHA_LAERTE.py
  3. Clique dentro da janela do Terminal e cole com ⌘ command + V. O comando aparece escrito depois do %.
  4. Aperte Enter e espere o % aparecer de novo (alguns segundos).
  5. Confira: apareceu OK - arquivo gerado: seguido do caminho da planilha.

5.2 Conferir a planilha gerada

Este comando gera a planilha de novo, num arquivo temporário, e compara célula por célula com a da pasta. Depois refaz a conta dos capítulos por outro caminho. Não altera nada.

  1. Clique em Copiar neste comando:
    python3 codigo/VERIFICA_PLANILHA_LAERTE.py
  2. Clique dentro da janela do Terminal e cole com ⌘ command + V. O comando aparece escrito depois do %.
  3. Aperte Enter e espere o % aparecer de novo (alguns segundos).
  4. Confira: o resultado no fim começa com OK: (1) 100% IDENTICO. Se a planilha já tiver notas preenchidas à mão, ele lista as diferenças; nesse caso é esperado.

As linhas em cinza foram resumidas aqui. No seu Terminal aparecem completas.

Passo 6

Abrir a planilha

Escolha uma das duas formas:

  • Pelo Finder: dê dois cliques na planilha TRABALHO LAERTE - …xlsx dentro da pasta.
  • Pelo Terminal: copie o comando abaixo, cole no Terminal e aperte Enter.
    open "TRABALHO LAERTE - Planilha de Pontuação (19 propostas) - Edital Universal 2026.xlsx"

Use o Excel. Os comentários das colunas T a Y aparecem ao passar o mouse sobre as células. O Numbers abre o arquivo, mas não salve por cima com ele.

Das próximas vezes: passo 2 (abrir o Terminal na pasta) e passo 5 (gerar e conferir).
